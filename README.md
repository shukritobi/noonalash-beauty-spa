# N by Noonalash Beauty Spa

Responsive concept website for N by Noonalash / NoonaLash Beauty Spa, positioned as a modern women-only self-care destination in Cyberjaya and Nilai.

## Website focus
- Women-only beauty spa positioning
- Head spa, facials, lashes, brows, nails, massage and body care
- Strong Fresha booking CTA
- WhatsApp enquiry CTA
- Cyberjaya and Nilai location sections
- Mobile-first responsive design
- Static deployment friendly for GitHub Pages or Cloudflare Pages

## Research used
Publicly available brand information from Noonalash social profiles, Fresha listings, Tatler Asia and local business listings. Prices, opening hours and treatment availability should be reconfirmed with the business before final production handover.

## Deployment
No build step is required. Publish the repository root as a static website.
